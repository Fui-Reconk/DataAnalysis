# 数据匹配与统计工具

基于 Python + CustomTkinter + Pandas 的可视化数据匹配与统计桌面应用。
加载多个 Excel（xls/xlsx）/ DBF 表格，以第一个数据源为基准做左连接匹配，
支持结构化条件过滤、自动清理冗余列、列名缩写替换、隐藏列，并导出双 Sheet 的 Excel 结果。

## 功能

- 📂 **文件加载**：多选加载 xls/xlsx/**DBF**（DBF 自动识别编码、中文 GBK 兼容，可与其他格式混合匹配）；支持**多工作表**——Excel 含多个 Sheet 时可自由勾选要添加的表；文件添加过任意表后即进入**暂存池**，之后可随时直接添加其其它表，无需重新选择文件；**导入/重载时自动按 `[column_map]` 替换列名缩写**；列表行**右键菜单**支持预览前几行、打开文件、在文件夹中显示、设为基准表、替换列名缩写、重载、移除等
- 🔗 **匹配配置**：主键下拉框只列**基准表**的列，选择唯一标识项后执行左连接；匹配完成后自动弹出结果预览（可在 `config.cfg` 关闭）；可**自动清理冗余列**——全空列、与基准表同名的重复列（该列有值的行与基准表一致即可删，未匹配行的空值不计差异；仅删非基准表列，基准表列永不删除）
- 🔍 **过滤筛选**：下拉框选择**列名**与**条件**（等于/不等于/大于/大于等于/小于/小于等于/包含/不包含/为空/不为空）并输入比较值；条件行可自由**增删**（默认一行），多行为「并且」关系；过滤完成后自动弹出结果预览（可在 `config.cfg` 关闭）
- 👁 **显示列（隐藏列）**：勾选对话框选择显示列，隐藏不需要的列（**基准表列不可隐藏**、始终显示）；影响过滤结果预览与导出，原始合并结果不变；调整后自动弹预览；隐藏列不出现在条件行的列名下拉框中
- 📈 **统计与导出**：**分组统计**——下拉框选择**分组列**（可不分组），配合条件行（同过滤页模式）统计符合条件的项目数量；「计算统计」仅弹出结果预览，不写入文件；「**📥 写入统计结果**」带二次确认，把当前结果**在内存中累积**为新的工作表（统计结果、统计结果_2…），点「导出结果」时与最终数据一并写入同一文件
- 🪵 **运行日志**：应用运行与错误写入 `logs/app.log`（1MB×3 自动轮转），`[log]` 可配置开关与级别
- ⚙️ **配置文件**：所有可调参数集中在根目录 `config.cfg`（INI 格式），修改后重启生效，无需改代码

## 环境要求

- Python 3.10+
- 依赖见 [requirements.txt](requirements.txt)

## 快速开始

```bash
# 1. 创建独立虚拟环境（一次即可）
python -m venv .venv

# 2. 激活环境
#    Windows (PowerShell)
.venv\Scripts\Activate.ps1
#    Windows (CMD / Git Bash)
.venv\Scripts\activate.bat
#    macOS / Linux
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行
python main.py
```

> 提示：也可不激活环境，直接使用虚拟环境内的解释器运行，例如
> `.venv/Scripts/python.exe main.py`

## 使用流程

1. **文件加载** → 「添加文件」选择 Excel / DBF 文件
   - 文件只有一个 Sheet 时直接添加；含多个 Sheet 时弹出勾选框，自由选择要添加的表
   - 同一文件的其他表：点「添加工作表」从暂存池直接添加（无需再次选择文件）
   - 每个已添加的数据源显示为「文件名 [工作表名]」，第一个为匹配基准表；左键点行选中、右键弹出菜单（预览/打开/定位/设为基准表/替换列名缩写/重载/移除），✕ 或「移除选中」可移除
   - 导入 / 重载时自动按 `[column_map]` 替换列名缩写
2. **匹配配置** → 从下拉框选择唯一标识项（主键）→ 点击「执行匹配」
   - 主键下拉框只列基准表的列；若某数据源缺少所选列，会提示具体文件、工作表与列名
   - 匹配键自动转字符串并处理空值，保证跨表一致比较
   - 匹配完成后自动清理冗余列（`[merge] auto_clean`）：全空列、与基准表同名的重复列（仅删非基准表列），并自动弹出结果预览（`[preview] auto_show_after_merge`）
3. **过滤筛选** → 每行选择列名、条件并输入比较值（点「添加条件」增行、✕ 删行）→ 「应用过滤」（可选步骤）
   - 选「为空 / 不为空」时无需输入比较值；条件或数值不合法时弹窗提示（含行号），程序不会崩溃；未执行匹配时提示先匹配
   - 过滤完成后自动弹出结果预览（`[preview] auto_show_after_filter`）
   - 「显示列」按钮打开勾选对话框，隐藏不需要的列（基准表列不可隐藏、不显示在列表中）；调整后自动弹预览（`[preview] auto_show_after_columns`），隐藏列同时从条件行的列名下拉框中消失
4. **统计与导出** → 选择分组列（可选）、填写统计条件 → 「计算统计」预览分组数量 → 点「📥 写入统计结果」把当前结果加入导出（内存累积，可多次追加）→ 「导出结果」一并写入
   - 不分组 + 无条件时统计总数量；分组列中的空值自成一组
   - 「导出结果」：Sheet「最终数据」（按显示列投影）+ 所有累积的统计工作表（统计结果、统计结果_2…）
   - 重新匹配 / 过滤 / 重置后，累积的统计清空（基于旧数据的结果自动失效）

## 配置文件

所有可调参数集中在根目录 [config.cfg](config.cfg)（INI 格式，含中文注释），按节划分：

- `[app]` 外观模式 / 主题色 / 窗口尺寸与标题
- `[sidebar]` `[nav]` `[font]` `[status]` `[file_list]` 界面布局、配色与文案
- `[preview]` 预览行数、导入 / 匹配 / 过滤 / 显示列调整后的自动弹预览开关
- `[merge]` 匹配后自动清理冗余列开关
- `[column_map]` 列名缩写 → 中文全称映射（右键「替换缩写」与导入时自动替换）
- `[context_menu]` 批量操作二次确认阈值
- `[dialog]` 复选对话框尺寸
- `[log]` 日志开关与级别
- `[files]` 文件对话框可选类型

修改后重启应用生效；删除该文件会回退到内置默认值。

## 常见问题

- **界面卡住**：匹配大文件时请耐心等待，界面底部进度条与状态栏会实时刷新。
- **读取 .xls 失败**：确认已安装 `xlrd`（见 requirements.txt）。
- **更换主题**：修改根目录 `config.cfg` 中 `[app]` 的 `appearance_mode`（system/light/dark）与 `color_theme`（blue/green/dark-blue），重启生效。
- **预览窗口太多**：导入、匹配、过滤、显示列调整都会按配置自动弹预览（全部非模态、可独立关闭）；可在 `config.cfg` 的 `[preview]` 节关闭对应开关。
